MOELCI-II AUTO LOGIN - RUNS ON THE PHONE, INSIDE CHROME
=======================================================

A Selenium/Python script can't drive Chrome from inside the same phone, so this
uses a Chrome bookmarklet instead. It fills the username and password, taps
"Sign in", and presses "Ok" on the confirmation.

ONE-TIME SETUP (on the phone)
1. Open Chrome and go to:
   http://177.143.2.44:8080/moelci-ii-queue-system/index.php
2. Tap the three dots menu > star icon to bookmark the page.
   Name it:  moelci
3. Tap the three dots > Bookmarks > long-press "moelci" > Edit.
4. Replace the whole URL with the code below (copy everything between the
   lines), then Save.

----- COPY FROM HERE -----
javascript:(function () { var u = document.getElementById('username'); var p = document.getElementById('password'); var b = document.querySelector('button.btn-login'); if (!u || !p || !b) { alert('Open the MOELCI-II login page first.'); return; } // Auto-press "Ok" if the confirmation is a native dialog window.confirm = function () { return true; }; u.value = 'Customer'; p.value = 'customer123'; b.click(); // Auto-press "Ok" if the confirmation is an on-page popup var tries = 0; var t = setInterval(function () { var els = document.querySelectorAll('button, input[type=button], input[type=submit], [role=button]'); for (var i = 0; i < els.length; i++) { var txt = (els[i].innerText || els[i].value || '').trim().toLowerCase(); if (txt === 'ok' && els[i].offsetParent !== null) { els[i].click(); clearInterval(t); return; } } if (++tries > 20) clearInterval(t); }, 250);})();
----- TO HERE -----

HOW TO RUN IT EACH TIME
1. Open the login page in Chrome (the URL above).
2. Tap the address bar and type:  moelci
3. Tap the bookmark suggestion that appears (the one with the star icon).
   Do NOT press Enter on the plain text.
4. It logs you in and presses Ok automatically.

NOTES
- To press Cancel instead of Ok, replace  return true  with  return false
  and  txt === 'ok'  with  txt === 'cancel'.
- The username and password are stored inside the bookmark on your phone.
- It only works while the login page is open in Chrome.
